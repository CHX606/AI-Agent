# RepoPilot PRD v0.1

## 1. 产品定义

RepoPilot 是一个面向代码仓库的 AI Coding Agent。

用户输入本地代码仓库和 Issue，RepoPilot 能够检索相关代码、制定修改计划、调用工具修改文件、运行测试，并根据测试错误进行重试，最终输出 Git Diff、测试结果和完整执行轨迹。

## 2. 目标用户

- 需要修复小型或中型代码仓库问题的开发者
- 希望自动完成重复性编码任务的开发团队
- 需要观察和评估 Agent 执行过程的 AI Agent 开发者

## 3. 核心使用流程

1. 用户选择代码仓库并输入 Issue。
2. 系统检查工作区和任务是否合法。
3. RepoMap 分析仓库结构。
4. Planner 生成结构化执行计划。
5. Executor 调用代码工具完成计划。
6. Test Runner 执行测试。
7. Verifier 判断任务是否完成。
8. 测试失败时，将错误反馈给 Planner 并重新修复。
9. 系统输出最终结果、Git Diff 和执行轨迹。

## 4. MVP 必须实现

- 创建和查询 Agent 任务
- 生成仓库文件树
- 搜索、读取和修改代码
- 运行测试并采集结果
- Planner、Executor、Verifier 执行闭环
- 至少一次基于测试错误的有效重试
- 保存工具调用、耗时、错误和测试结果
- 限制路径、命令、步骤数、重试次数和输出长度
- 支持通过 SSE 查看实时执行轨迹
- TypeScript Gateway 与 Python Agent Worker 分离

## 5. MVP 暂不实现

- 多 Agent 协作
- VS Code 或其他 IDE 插件
- 向量数据库
- 长期用户记忆
- 任意 Shell 命令
- Java 等多语言仓库修复
- 大型前端管理后台
- SWE-bench 排行榜级评测

第一版只支持小型 Python 仓库和 pytest。

## 6. 并发设计目标

Gateway 不直接执行 Agent 任务，只负责创建任务、查询状态和推送事件。

Agent 任务进入队列，由独立 Worker 消费。增加 Worker 数量即可扩展并发能力。单个任务失败或阻塞不得占用整个 API 服务。

前三天先完成单任务闭环所需的基础工具，不提前实现大规模部署。

## 7. 成功定义

给定一个带失败测试的 Python 示例仓库和明确 Issue，RepoPilot 必须能够：

1. 找到相关代码和测试。
2. 生成并应用补丁。
3. 运行 pytest。
4. 在第一次测试失败后读取错误信息。
5. 至少完成一次有效修复。
6. 最终让测试通过。
7. 输出 Git Diff 和完整执行轨迹。
8. 拒绝访问工作区之外的文件。

## 8. 失败定义

出现下列任意情况时，任务判定为失败：

- 超过最大步骤数或最大重试次数
- 超过时间或 Token 预算
- 尝试访问工作区之外的路径
- 尝试运行未授权命令
- 无法生成有效补丁
- 测试始终无法通过
- Agent 重复调用相同工具且没有产生新信息

失败必须返回明确的错误类型、执行阶段和已有轨迹，不能静默结束。
