## 完成的修复

1. 标题栏下方的分隔线移到完整窗口宽度的内容容器顶部，覆盖原生窗口控制按钮下方。实际便携包校验了分隔线位置、宽度和已渲染的边框；Windows 缩放下允许小于 1 个 CSS 像素的宽度取整差异。
2. 点击运行中的主按钮后，界面同步显示“已停止”，收起问答/暂停卡片并移除转圈、耗时和内部暂停过程提示。后台沿用取消、保存与清理链路。晚到的状态与模型事件不能恢复已停止的界面；切换对话后，旧任务事件不会写入新对话。停止后排队消息保留，不会自动发出。
3. 文件树、编辑器标签和路径导航统一使用 Material Icon Theme 5.39.0 官方图标及关联清单。支持目录开闭、特殊文件名、文件类型、未知类型兜底与深浅主题。1,251 个 SVG 随包离线加载，未增加运行时依赖；原始 MIT 许可保留。

按 AGENTS.md 要求先拆分已有超长文件。main、interaction-view、stream-view、repository-view 和 styles 的原有职责分别迁入 application、interaction、stream、repository、styles 目录。
