# Bit Agent 2026-10-06 的改动

接在 [1.0 之后的改动](CHANGES_AFTER_1.0.md) 后面，包含 2026-10-06 的 14 个提交（`64e9054` 至 `7bb32d1`），共改动 140 个文件。

发布包：`release/BitAgent-2026-10-07T04-15-35-488Z/Bit Agent.exe`（整个目录一起使用），已通过完整打包验收。

> 全部改动都已提交到本地，**还没有推送**（`main` 比 `origin/main` 多 30 个提交）。

## 一、概览

1. **内置终端**：对话区下方可以开 PowerShell，支持多个标签、查找，也能把选中内容引用到对话里。
2. **内置浏览器**：右侧的浏览器面板，有标签页、地址栏、书签和历史、下载，网站要权限时会询问。
3. **Agent 可以操作浏览器**：Agent 能打开网页、读取内容、点击、输入、截图。读取类操作不用批准，动手类操作每次都要你批准。
4. **界面参照 Claude Code**：
   - 左侧栏可以收起。
   - 内容放在居中的 768px 一栏里。
   - 整个界面可以用 Ctrl+加号、Ctrl+减号缩放。
   - 对话里不再有圆点和缩进。
   - 以前的轮次直接显示执行步骤。
5. **对话操作**：
   - 可以复制回答、用户消息和代码块。
   - 最后一轮可以编辑或重新生成。
   - 审阅改动时差异更好读。
6. **外部工具（MCP）**：远程服务可以填请求头，例如带令牌的 `Authorization`；设置面板也重新整理了。
7. **修复**：
   - 窄窗口下浮动面板盖住标题栏的问题。
   - 基础检查找不到项目自己 `.venv` 的问题。
   - 界面缩放后浏览器面板宽度回不去的问题。

## 二、内置终端（`1e1f895`、`996ebf5`）

- **怎么打开**：
  - 在对话区下方运行 PowerShell（装了 pwsh 时用 pwsh）。
  - 用顶栏按钮或 **Ctrl+`** 打开或关闭。
  - 面板高度可以拖动。
  - 隐藏后终端还在运行，也可以重新启动。
  - 颜色跟随亮色、暗色主题。
- **多个终端**：
  - **Ctrl+Shift+T** 新开一个终端标签，每个标签是独立的会话。
- **常用操作**：
  - 右键：有选中内容时复制，没有选中时粘贴。
  - Ctrl+点击输出里的链接：在内置浏览器打开。
  - **Ctrl+Shift+F**：查找，匹配处会高亮。
  - "引用到对话"：把选中内容放进输入框，作为代码块；没有选中时引用最后 60 行。
- **代码仓库页**：终端跟着显示，位置在编辑区和状态栏之间。
- **从哪个目录启动**：在当前工作区启动（会先校验工作区）；没有工作区时在用户目录启动。
- **安全**：
  - 页面只能启动系统 Shell。
  - 每个窗口只能控制自己的终端。
  - 输入有长度上限。
  - 关闭窗口时，它的终端一起结束。
- **技术说明**：
  - 终端用 node-pty 和 xterm.js 实现。
  - 使用 node-pty 自带的 ConPTY，避免在 Electron 里关闭终端时出现 `AttachConsole` 错误。
  - 页面的安全策略（CSP）保持严格。xterm 自动生成的样式，改为放进终端内部的样式表。
- **缩放**：终端原来自己的字号缩放已去掉，统一用整个应用的缩放（见第五部分）。

## 三、内置浏览器（`ef5e861`、`996ebf5`）

- **位置**：
  - 右侧面板，和"任务详情"共用这一栏。
  - 面板宽度可以拖动，也可以用键盘调整。
  - 在代码仓库页也保持打开。
- **标签页**：
  - 显示网站图标。
  - 下次打开浏览器时恢复上次的标签，只有当前标签会加载。
  - 快捷键：Ctrl+T 新建，Ctrl+W 关闭，Ctrl+Tab 切换。
  - `target=_blank` 的链接和鼠标中键点击的链接会在新标签打开。
- **地址栏**：
  - 可以输入网址、本机开发地址（比如 `localhost:5173`），或者直接搜索。
  - 输入时会从书签和历史里给出建议。
  - **Ctrl+D** 添加书签。
- **起始页**：列出本机正在运行的开发服务器、书签和最近访问的网站。
- **打不开时**：显示通俗的错误说明，例如"出于安全原因，浏览器不允许访问这个端口"。
- **其他功能**：
  - 页内查找、网页缩放、打印、右键菜单、开发者工具。
  - 文件下载到"下载"文件夹。可执行文件只在文件夹里显示出来，不会直接运行。
  - 网页视频等可以全屏，退出后回到面板。
- **对话里的链接**：回答里的链接在内置浏览器的新标签打开；按住 Ctrl 点击时用系统浏览器打开。
- **权限、登录和证书**：
  - 网站请求摄像头、麦克风、位置、通知、读取剪贴板时，面板上方会出现提示条询问你。你的选择保持到应用重启。
  - 遇到 HTTP 登录或代理登录，在面板里填写。密码不会保存。
  - 遇到证书错误，可以在警告后只对这一张证书放行，同样保持到应用重启。
- **安全**：
  - 使用独立的持久会话，和应用本身的数据分开。
  - 只允许打开 http 和 https 地址。
  - 浏览器的用户代理（UA）里不带 Electron 标识。
  - 网页里按应用快捷键仍然有效。
- **实现方式**：
  - 每个标签是一个原生网页视图，始终和面板对齐。
  - 弹窗或菜单盖住网页区域，或者正在拖动宽度时，网页换成一张截图显示，避免原生视图盖在弹窗上面。

## 四、Agent 操作浏览器（`5b39ba4`）

- **怎么接入**：
  - 桌面端在 `127.0.0.1` 上提供一个内置 MCP 服务，每次启动生成新的令牌，令牌放在请求头里传递。
  - 运行时把它当作名为"browser"的外部工具接入。
  - 它不出现在设置里，也不会在对话里提示"已连接"。
- **可用的工具**：
  - 打开网页
  - 读取页面：返回页面文字，以及给可交互元素编的号
  - 点击、输入、选择、按键
  - 前进、后退
  - 截图
  - 查看控制台输出
  - 等待
  - 管理标签页
- **用哪个标签**：
  - Agent 在自己的标签里操作，标签上标有"Agent"。
  - Agent 开始操作时，浏览器面板会自动打开。
  - 读取类工具也可以看你当前打开的那个标签。
- **批准规则**：
  - 读取类工具不需要批准，只读模式下也能用。
  - 点击、输入等动手类操作每次都会询问，询问的文字是专门为浏览器写的。
  - 可以选择"本对话内都批准"。
- **安全**：
  - 脚本在隔离环境里运行。
  - 输入文字时不会抢走你的键盘焦点。
  - 拒绝往密码框里输入。
  - 只允许 http 和 https。
  - 网页内容会标注为"不可信"，提醒模型不要照着网页里的指令做。
- **截图**：
  - 截图不放在工具结果里，而是作为图片发给模型。
  - 只发送最近两张。
- **对话里的显示**：这类工具行显示为"浏览器 · 打开网页"这样的格式。
- **文档**：[docs/MCP.md](MCP.md) 新增了内置浏览器的说明。

## 五、界面和布局

### 1. 参照 Claude Code 的整体布局（`8a99db8`）

- 对话内容和输入框放在同一个居中的 **768px** 栏里。左右留白一样，输入框和上面的内容对齐。
- 窗口变窄时，两边留白自动缩小。

### 2. 界面缩放（`8a99db8`）

- **快捷键**：
  - **Ctrl+=** 放大，**Ctrl+-** 缩小，**Ctrl+0** 回到标准大小。
  - 按住 Ctrl 滚动鼠标滚轮也可以缩放。
- **档位和记忆**：
  - 档位和 Chrome 一样，从 50% 到 200%。
  - 会记住上次的大小，保存在 `preferences.json`。
- **跟随缩放**：终端和浏览器跟着一起缩放，浏览器网页区域的位置不会错开。

### 3. 对话输出（`8a99db8`、`7bb32d1`）

- 回答正文和工具行前面不再有圆点。
- "读取了 6 个文件""修改文件 xxx.py"这类工具步骤：
  - 是一行灰色、不加粗的字，点击可以展开。
  - 修改文件时，用绿色的 `+N`、红色的 `−N` 小标签显示增删的行数。
- 正在进行的步骤，文字会轻微地一明一暗，代替原来闪烁的圆点。
- 子 Agent 的步骤（例如"测试 Agent 已返回…"）和"已停止"这类提示，不再缩进。
- **以前的轮次直接显示执行步骤**：
  - 去掉了"查看执行过程"按钮。打开以前的对话时，各轮的步骤按顺序自动补上，补上之前先显示回答。
  - 某一轮的步骤读取失败时，那一轮只显示回答。
  - 切换到别的对话时，还没补完的会停止。
- 回答内容里的编号列表、圆点列表照常显示。

### 4. 左侧栏可以收起（`91fb22a`）

- **怎么收起**：点图标栏里品牌标志下面的按钮，或者按 **Ctrl+B**，和 VS Code、Claude Code 一样。
- **收起后**：只保留最左边的图标栏，主区域变宽。
- **记住状态**：对话页和代码仓库页共用这个状态，重新加载后保持不变。
- **窄窗口**：本来就只显示图标栏，所以这时不显示这个按钮。

### 5. 小问题修复（`7302b12`、`8a99db8`）

- **窄窗口下的浮动面板**（窗口宽度 1050px 及以下）：
  - 浏览器和任务详情变成浮动面板时，以前会盖住标题栏和系统的最小化、最大化、关闭按钮，底部还会空出一条缝。现在它们从标题栏下面开始。
  - 在对话页，浮动面板从顶栏下面开始。状态和终端、浏览器、任务详情这几个按钮一直看得见、点得到。
  - 代码仓库页以前为浮动的浏览器多留了一列，编辑区只剩一半宽，现在占满宽度。
- **浏览器面板宽度**：窗口变窄或界面放大时，面板会临时收窄；恢复后回到你自己设的宽度，不会一直保持收窄。
- **浏览器标签标题**：标题能用满整个标签宽度，只有显示关闭按钮时才让出位置。
- **菜单图标**："模型设置""执行设置""日志与诊断"换成了各自不同的图标。

## 六、对话操作（`4c5d646`、`9d394d1`、`dedb20e`）

- **复制**：
  - 每条用户消息和每个已完成的回答下面都有复制按钮。复制回答时，以 Markdown 格式复制当前显示的全部文字。
  - 代码块上方有一条标题栏，显示语言，并带复制按钮。
  - 复制通过主进程写入剪贴板，窗口没有焦点时也能复制。
- **编辑和重新生成最后一轮**：
  - 每一轮开始时保存对话上下文和工作记忆。只有最后一轮保留这个保存点。
  - 撤回时会做三件事：撤销这一轮对文件的修改，恢复上下文，删除这一轮。如果这一轮之后你又改过这些文件，会拒绝撤回。
  - 如果撤回的是唯一的一轮，整个对话会被删除。
  - "编辑"把原来的文字和图片放回输入框；"重新生成"把它们原样再发一次。
- **审阅改动的差异显示**：
  - 显示新旧行号、语法高亮，以及每个文件的 `+N −M`。
  - 可以在合并视图和左右对照视图之间切换，会记住你的选择。
  - 修复了一个识别问题：被删除的行如果以 `--` 开头，以前会被误当成文件头。

## 七、外部工具（MCP）（`dcb81e8`、`750905f`）

- **请求头**：
  - 远程（HTTP）服务可以按 `名称: 值` 的格式填写请求头，用于需要令牌的服务。
  - 请求头的值和本地（stdio）服务的环境变量一样，用 Windows 的加密存储保存。页面上只能看到请求头的名称；没有重新填写时，继续使用已保存的值。
  - 带请求头的连接不跟随重定向，防止令牌被发到别的网站。由 HTTP 或 MCP 协议自己管理的请求头不允许填写。
- **已验证的官方服务**：OpenAI 文档 MCP（`https://developers.openai.com/mcp`）已接入并测试可用。它是只读的。
- **设置面板**：
  - 每个服务显示成一张卡片，带主题色的开关。停用的服务显示为变暗，地址用等宽字体显示在一行里。
  - "自动批准"的说明改短了，并注明只在编辑模式下生效。
  - 保存栏固定在面板底部，会提示有没有未保存的改动；没有改动时不能点保存。
  - 点"+ 添加服务"会打开一张带标题的表单卡片，滚动到那里并定位到名称输入框。表单有取消按钮。

## 八、修复：基础检查使用项目自己的 `.venv`（`64e9054`）

**问题**：基础检查在工作区的副本里运行，副本不包含 `.venv`，所以以前会退回到软件自带的 Python，报"缺少依赖"。

**修复**：

- 改用原工作区里的 Python 解释器，先找项目目录，再找工作区根目录。
- 允许沙箱读取这个虚拟环境，以及 `pyvenv.cfg` 里写的基础 Python。
- 把副本里的源码放在 `PYTHONPATH` 最前面。这样即使项目是以可编辑模式安装的，也不会导入原工作区里的文件。沙箱运行器新增了只限工作区路径的 `pythonPath` 字段。
- 独立验收使用同样的导入路径。

## 十、需要知道的行为变化

- **终端字号**：终端不再有单独的字号缩放，Ctrl+=、Ctrl+-、Ctrl+0 现在缩放整个应用。
- **以前的轮次**：打开以前的对话会自动读取各轮的执行过程，轮次多的时候，步骤会稍晚一点出现。
- **浏览器的授权**：网站权限的选择和证书放行都只保持到应用重启。
- **Agent 操作浏览器**：Agent 读取网页不需要批准；点击、输入等操作每次都要批准，除非你选了"本对话内都批准"。
