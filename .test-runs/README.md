# .test-runs：任务运行副本与现场记录

这里保存某些测试、评测或手工联调使用的工作目录。它可能包含完整源码、Agent 的实际改动以及这次运行的结果，不只是一个失败测试名单。

本目录只有这份说明纳入 Git；其余运行副本和现场记录由 `.gitignore` 排除，但仍保留在本机。不要使用清理缓存的方式整体删除本目录。

## 当前工作流引擎例子

`workflow-engine-f07cd13585f643ef924e61d78e2c6d98` 是一份已留存的工作流引擎运行目录。后面的长编号用于区分运行，不是文件版本号。

| 内容 | 用途 |
| --- | --- |
| `workspace/workflow_engine` | 这次运行实际处理的工作流引擎代码。 |
| `workspace/tests` | 这道题的验收测试。 |
| `workspace/README.md` | 当前副本说明和原题要求。 |
| `artifacts/events.sse` | 保存下来的实时执行事件。 |
| `artifacts/gateway-result.json` | 最终状态、回答、工具调用和修改文件等信息。 |
| `artifacts/tests-before.json` | 运行前记录的测试文件路径和哈希，供后续比较。 |

`tests-before.json` 不是测试成绩；哈希表示文件内容的指纹，可以帮助判断文件有没有变化。

## 和自动清理的评测临时目录有什么区别

某些 EvalRunner 会在这里创建临时子目录，并在结束后自动清理；某些手工联调会留下完整现场。不能要求所有子目录都长成上面这个例子的结构。

## 删除会怎样

删除某个运行目录，会连同其中修改过的代码和日志一起删除。若还要学习或排查这次运行，应保留它。重新运行可以产生新结果，但无法保证恢复同一次运行的历史。
