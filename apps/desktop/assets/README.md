# Bit Agent application icon

The icon follows the existing orange (`#d96c2f`) rounded B brand from the desktop navigation. `icon.png` is 512x512 RGBA. `icon.ico` contains 16, 20, 24, 32, 40, 48, 64, 96, 128, and 256-pixel images.

Generated using Pillow by `scripts/desktop-package/generate-icon.py`; the Windows Consolas Bold font is rendered into the image and is not bundled. The Windows package uses the same PNG for BrowserWindow and the ICO for the executable resource.
