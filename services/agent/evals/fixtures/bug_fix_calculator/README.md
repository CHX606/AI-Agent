# Calculator Bug-Fix Fixture：计算器评测原题

更新日期：2026-09-04。

这是 Bit Agent 的故障修复评测原件。它是一道故意带有功能错误的小题，用来检查 Agent 能否自己阅读代码、定位问题、修改代码并通过验收。

这里保留错误是题目的需要，不表示项目维护者忘了修复业务代码。评测器会复制一份临时工作区，Agent 在副本里做题。

## 文件分别做什么

| 内容 | 用途 |
| --- | --- |
| `calculator.py` | 提供简单整数计算功能，是 Agent 要调查和修复的代码。 |
| `tests/test_calculator.py` | 判断计算行为是否正确的验收测试。 |
| `README.md` | 说明题目背景。 |

本说明不直接给出修复答案，避免把调查过程变成照抄答案。

## 谁在使用它

`services/agent/evals/run_bug_fix.py` 和 `run_multi_agent_bug_fix.py` 都引用这份题目。它们的评测规则允许修改 `calculator.py`，保护测试和 README 等文件。

这里的“不可变”指 Agent 参加一次评测时不能修改题目原件或副本中的受保护文件。维护者可以有意识地维护题目文档；这不改变评测程序对 Agent 的限制。

## 结果保存在哪里

评测产物默认放到根目录 `artifacts/evals`。临时做题目录与持久化结果不是同一个目录；一次评测结束后，可以保留结果而清理临时副本。
